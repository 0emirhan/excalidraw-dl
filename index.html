Excalidraw DL

Download any read-only Excalidraw presentation as an editable .excalidraw file.

1 — Install the bookmarklet

Excalidraw DL

Drag this button to your browser's bookmarks bar
(or right-click → Bookmark this link)

2 — How to use

1
Open any link.excalidraw.com/p/readonly/… page
2
Wait for the drawing to fully load
3
Click Excalidraw DL in your bookmarks bar
4
The .excalidraw file downloads instantly — open it in excalidraw.com or any local install to edit it
